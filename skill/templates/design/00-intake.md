what they *mean* for the design.

|---|---|---|---|
| play_posture | | | body map (seated/standing heights), turning |
| game_machine | | | where Steam Input, logs and deploys go |
| sickness | | | comfort defaults |
| immersion_style | | | immersion review verdicts |
